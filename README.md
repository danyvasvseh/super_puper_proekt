# super_puper_proekt

# пользовательские сценарии
## сценарий 1 - выбор 

1. пользователь нажимает кнопку с названием стека, который он выбрал
2. пользователь выбирает из списка (легко/сложно) уровень сложности
3. окно загрузки
4. пользователь попадает в окно диалога и видит первый вопрос

## сценарий 2 - интервью

1. пользователь получает вопрос и пишет ответ
2. после ответа генерируется и пишется новый вопрос
3. после 5 вопросов интервью заканчивается, появляется кнопка генерации отчёта

## сценарий 3 - отчёт

1. пользователь нажимает кнопку "создать отчёт" и выбирает сохранённое интервью
2. окно загрузки
3. пользователь видит отчёт и кнопку скачать
4. пользователь нажимает кнопку скачать и файл оказывается в заранее подготовленной папке

# необходимо разработать

1. создать элементы начальной навигации: выбор сложности, окно загрузки
2. создать окно чата: отрисовка сообщений,
3. отрендерить отчёт по заданному тексту
4. подключится к нейронке. Создать начальный промпт. Обеспечить возможность отправления и получения ответа (в нужном виде)
5. создать сохранение истории при выходе или завершении интервью
6. получить отчёт по сохранённому интервью
7. создать генерацию pdf отчёта по тексту ответа нейронки
