# Auction Game (Python)

Проект реализует простую игру-аукцион и набор агентов (стратегий), которые могут в неё играть. Архитектура позволяет легко добавлять новых агентов и проводить эксперименты.

---

## 📦 Структура проекта

```
project/
│
├── auction.py     # логика игры
├── agents.py      # реализации агентов
└── README.md
```

---

## ▶️ Как запустить игру

1. Убедитесь, что установлен Python 3.8+
2. В `auction.py` (или отдельном `main.py`) создайте агентов:

```python
from agents import EVAgent, AdaptiveAgent
from auction import Game

agent1 = EVAgent("EV")
agent2 = AdaptiveAgent("Adaptive")

game = Game(agent1, agent2)
game.play()
```

3. Запустите:

```bash
python auction.py
```

или если есть `main.py`:

```bash
python main.py
```

## 🤖 Как создать своего агента

Все агенты наследуются от базового класса `Agent`.

### Интерфейс

```python
class Agent:
    def make_bid(self, context: dict) -> int:
        pass
```

---

### Пример простого агента

```python
from agents import Agent

class MyAgent(Agent):
    def make_bid(self, context):
        my_points = context['my_points']
        return min(10, my_points)
```

---

### 📥 Подключение агента

```python
from agents import MyAgent
```

## 🧠 Формат `context`

Каждому агенту передаётся состояние игры:

```python
{
    'round': int,
    'my_points': int,
    'opponent_points': int,
    'history': [
        {
            'my_bid': int,
            'opponent_bid': int,
            'value': int
        },
        ...
    ]
}
```

## 🎮 Правила игры

* У каждого игрока: **200 очков**
* Игра длится **5 раундов**
* В каждом раунде:

  * генерируется скрытая ценность предмета: **10–30**
  * игроки делают ставки
  * выигрывает тот, у кого ставка больше

### Результаты раунда:

| Условие   | Результат      |
| --------- | -------------- |
| Победа    | `+value - bid` |
| Поражение | `0`            |
| Ничья     | `0`            |

## 🧩 Описание классов

---

### 📁 `auction.py`

---

### `class Game`

Основной класс, управляющий игрой.

#### Конструктор

```python
Game(agent1: Agent, agent2: Agent, rounds: int = 5)
```

* `agent1`, `agent2` — игроки
* `rounds` — количество раундов

---

#### `play()`

Запускает игру:

* выполняет раунды
* запрашивает ставки
* обновляет очки
* выводит результат

---

#### `_get_context(agent, opponent, round_number)`

Формирует состояние для агента.

---

#### `_validate_bid(bid, max_points)`

Проверяет корректность ставки:

* неотрицательная
* не больше доступных очков
* приводит к допустимому диапазону

### Примеры агентов

---

### `MirrorAgent`

* 1-й ход: случайный
* далее: копирует ставку оппонента

---

### `EVAgent`

* ориентируется на ожидаемую ценность (≈20)
* избегает переплаты

---

### `AdaptiveAgent`

* меняет стратегию:

  * проигрывает → агрессия
  * выигрывает → осторожность

---

### `MinimaxAgent`

* перебирает ставки
* выбирает стратегию с максимальным минимальным выигрышем

---

### `BayesianAgent`

* оценивает распределение ставок оппонента
* выбирает ставку с максимальным ожидаемым выигрышем

---

### `PunisherAgent`

* хаотичное поведение
* усиливает ставки против агрессивного оппонента

---

### `QLearningAgent`

* обучаемый агент
* использует Q-learning
* накапливает опыт в `Q-table`

## 📌 Замечания

* агенты **не должны менять состояние игры**
* вся логика очков — внутри `Game`
* агенты принимают решения только на основе `context`
